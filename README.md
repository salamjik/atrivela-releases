# Atrivela — official downloads

Free desktop companion for Windows x64. Native glass widgets above your existing wallpaper, local notes, weather and PC monitoring. Windows taskbar, desktop shortcuts and virtual desktops stay available.

Official builds are available in Releases. Source code is private. Release update metadata is signed; the desktop validates the pinned publisher key, package hash and size. The Windows EXE is currently an unsigned preview (no Authenticode certificate).

No registration or payment is required for this preview. This repository contains distribution metadata and official packages only; no signing keys, API tokens, accounts or source code.
